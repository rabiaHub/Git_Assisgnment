# 🎬 CineVerse – Movie Hub

**Course:** Web Development  
**Created by:** Rabia Yaseen

## 📌 About the Project

CineVerse is a movie hub website designed to provide users with an interactive cinema experience. It showcases currently showing movies, weekly showtimes, ticket prices, and a ticket booking form.

This project is developed using HTML, CSS, and JavaScript to practice front-end web development and DOM manipulation.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive functionality

## ✨ Features

- Light/Dark Mode Toggle
- Movie Listings and Descriptions
- Weekly Showtime Filtering
- Interactive Movie Ticket Selection
- Automatic Ticket Price Calculation
- Ticket Booking Form
- Read More Functionality
- Character Counter for Special Requests
- Movie Image Gallery

## 🚀 How to Run the Project

**Live Demo:** https://rabiahub.github.io/Git_Assisgnment/
Alternatively, to run the project locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default browser.

**Note:** For the best experience, use a modern browser such as Google Chrome or Mozilla Firefox.
